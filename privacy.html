Application: Personal rclone Drive Backup
Operator: darttroll
Last updated: October 11, 2026

Purpose and authorized users

This application is a private, non-commercial OAuth configuration for the open-source rclone tool. It is used only to manage files and backups belonging to the operator or Google accounts that have independently granted access. It is not available as a public service.

Google user data accessed

With explicit Google OAuth consent, rclone may access Google Drive files and folders, their names, contents, sizes, timestamps, checksums, and other metadata. The granted Drive permission can allow listing, reading, creating, updating, moving, or deleting files. The operator configures and controls which operations are actually performed.

Use of Google user data

Data is used solely for owner-directed file backup, migration, synchronization where explicitly configured, recovery, and integrity verification. File contents and metadata may be processed on a server controlled by the operator and transferred to other storage services selected and authorized by the operator for these tasks.

Storage, security, and retention

OAuth refresh tokens and application credentials are held in access-restricted configuration files on the operator's server; they are not published on this website. Backup file copies and operational logs may be retained for as long as needed by the operator's backup policies or storage provider settings. Access to these files is restricted to authorized operators and connected storage services.

Sharing and advertising

Google user data is not sold, used for advertising, or provided to unrelated third parties. It is transferred only to storage providers and systems explicitly selected for the owner's backup workflow. This informational website does not include advertising trackers, analytics scripts, or a user registration form. GitHub Pages, as the website host, may process standard access data under GitHub's policies.

Revoking access and deleting data

Google OAuth authorization can be revoked at any time through the relevant Google Account's third-party connections settings. The operator can also remove locally stored OAuth tokens and delete backup files and logs from the relevant server or connected storage service.

Contact

Questions can be addressed to the operator through GitHub repository issues. Issues are public; do not post passwords, access tokens, personal information, or file contents in an issue.
